cara kerja

      

        

          
01

          
tokenize

          
setiap baris lirik dipecah jadi token — keyword pink, properti biru,
          string krem, komentar hijau — persis pewarnaan di video aslinya.

        

        

          
02

          
ketik per karakter

          
satu karakter tiap ±55 ms dengan jeda acak kecil, lalu jeda
          380 ms di akhir baris. kursor blok pink berkedip mengikuti ketikan.

        

        

          
03

          
loop

          
setelah baris terakhir, animasi diam 3,2 detik lalu mulai lagi dari
          nol. klik di mana saja di editor (atau tombol replay) untuk mengulang
          kapan pun.

kenapa sesederhana ini

      

        

          
tanpa dependensi

          
html + css + js polos. tidak ada framework, tidak ada build step,
          tidak ada request ke mana-mana.

        

        

          
jalan di mana saja

          
buka file-nya langsung, atau serve statis apa pun. offline pun
          jalan, font fallback monospace sistem.

        

        

          
kontrol penuh

          
jeda, ubah kecepatan 0.5×–2×, atau replay kapan pun —
          tanpa reload halaman.

        

        

          
jujur soal audio

          
tidak ada audio di repo ini. ini animasi ketik, bukan pemutar lagu —
          liriknya yang jadi bintangnya.
